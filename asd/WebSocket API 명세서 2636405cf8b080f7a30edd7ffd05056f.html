  • 천사카드 (ANGEL): 방어용 카드, 뽑으면
    보유하다가 피해 시 자동 소모즉발카드 (INSTANT): 뽑는 즉시 효과 발동, 별도
  • 즉발카드 (INSTANT): 뽑는 즉시 효과 발동, 별도
    보관하지 않음

    🔄 카드 뽑기 흐름 (DRAW_CARD)

    1. 카드 뽑기 요청: 플레이어가 찬스칸에 도착하여
      카드 뽑기
    1. 뽑을 카드 결정:
    • DB에서 모든 카드 조회
    • 천사카드가 이미 누군가 보유중이면 제외
    • 나머지 카드 중 랜덤 선택
    1. 카드 타입별 처리:
    • 천사카드: 플레이어 보유 상태로 변경 +
      덱에서 제거
    • 즉발카드: 즉시 효과 적용 (돈/위치/감옥 등)

    🛡️ 천사카드 방어 흐름

    1. 자동 방어: 플레이어가 피해를 받을 상황 발생
    1. 천사카드 보유 확인: 해당 플레이어가
      천사카드를 가지고 있는지 체크
    1. 방어 발동:
    • 천사카드를 플레이어에게서 제거
    • 덱에 천사카드 다시 추가 (다른 플레이어가
      뽑을 수 있도록)
    • 피해 무효화

    ⚡ 즉발카드 효과 분류

    효과값(effectValue)에 따른 분류:

    • effectValue = 10: 감옥 이동
    • |effectValue| ≥ 10000: 돈 증감 효과
    • |effectValue| < 10000: 위치 이동 효과

    🔒 동시성 제어

    천사카드 중복 방지:

    1. 초기 상태: angelCardInDeck = true (덱에
      천사카드 존재)
    1. 누군가 뽑음: angelCardInDeck = false (다른
      사람은 못 뽑음)
    1. 사용 완료: angelCardInDeck = true (다시 뽑기
      가능)

    📊 데이터 저장 구조

    • 천사카드: 플레이어 상태의 anglecard 플래그로
      관리
    • 즉발카드: 별도 저장 없음, 뽑는 즉시 소모
    • 게임 상태: Redis에 CreateMapPayload 형태로
      저장

맵 정의

칸 정의
일반땅 :
1. 아무도 사지 않은 경우 - 일정 금액을 지불하고 증서구매, 건설 가능
2. 나의 땅인 경우 - 추가 건설이 가능한 경우 건설 가능. 외에는 아무 효과 X, 아니면 월세 받기?
3. 적의 땅인 경우 - 증서와 건물의 가격 총합의 일정 배율만큼 통행료 지불. 땅을 구매하고 싶은 경우 증서와 건물의 가격 총합의 일정 배율만큼 지불하고 통째로 구매 가능

특수칸 : 아래 각 특수칸마다 기재

찬스칸 :
1. 그 땅을 밟은 경우 찬스카드 한 장을 랜덤으로 뽑음
2. 여기서 나오는 카드는 금융 정책, 이슈, 게임카드 중 1개
3. 천사카드를 제외한 모든 카드는 즉발로 효과 발생
4. 천사카드는 보유 가능. 통행료 지불이나 기타 부정적인 효과가 발생한 경우 천사카드를 사용하여 회피 가능.
5. 천사카드는 게임 내 단 1장. 누군가 보유하다가 사용하면 다시 찬스카드 목록으로 들어감.

싸피특별땅 :
1. 땅만 구매 가능(건설 X)
2. 5개의 싸피특별땅을 모두 구매할 경우 승리 또는 메리트 부여

이자 들어올 때 메시지

다른 사람 땅 들어갔을 때 돈 회수 메시지 = 통행료 지불 / ㅇㅇ 님이 ㄷㄷ 님의 땅에 들어가서 통행료 지불

감옥 메시지 (첫 회) = 누가 감옥에 들어갔냐?

감옥 갔을 때, 자기가 몇 턴 뒤에 나갈 수 있는지 메시지(계속) == ㅇㅇ 님이 감옥이라 N턴뒤에 나갈 수 있다 == OO 의 턴마다 나옴

세계여행 == ㅇㅇ 이 세계여행

월급 들어올 때 메시지 == 플레이어 이름 + 돈 들어왔다
