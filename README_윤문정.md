## 1. 프로젝트 기획 및 팀 리딩
- 팀장으로서 프로젝트의 초기 방향성을 설정하고 팀원들의 의견을 조율하는 역할을 주도적으로 수행했습니다.

- 아이디어 구체화 및 기술 스택 선정: 팀원들과의 논의를 통해 특화 프로젝트의 핵심 아이디어를 구체화하고, 이를 구현하기 위해 기술 스택을 함께 결정했습니다. 결과 핀테크와 부루마블을 결합한 '핀블' 프로젝트를 기획하게 되었습니다. 

- 회의 총괄: 팀의 진행 상황을 점검하고, 앞으로 나아갈 방향에 대해 논의를 이끌었습니다.

- 팀 활동 주도: 지난주 필드트립 활동을 주도적으로 계획하고, 진행하며 팀원들과의 소통과 협업의 기회를 만들고자 노력했습니다.

- 애자일 개발 환경 구축 (Jira): 프로젝트의 효율적인 진행을 위해 Jira를 사용해 첫 번째 스프린트를 생성했습니다. 기능 명세서를 바탕으로 초기 백로그를 작성하고, 개발에 필요한 기초 작업들을 태스크로 등록하여 애자일 개발 프로세스의 기반을 마련했습니다.

## 2. UI/UX 설계 및 프로토타이핑
- 프로젝트의 Frontend 개발을 담당하고, 아이디어를 시각적으로 구체화하는 작업을 담당했습니다.

- 디자인 리서치 및 와이어프레임 제작: '아기자기하고 친근한 금융 게임'이라는 컨셉에 맞는 다양한 디자인 레퍼런스를 분석하고, 이를 바탕으로 게임의 전체적인 화면 흐름을 담은 와이어프레임을 제작했습니다.

- HTML/CSS 프로토타입 구현: 제작된 와이어프레임을 바탕으로, 실제 웹 브라우저에서 UI/UX를 직접 확인하고 테스트할 수 있는 HTML/CSS 기반의 디자인 시안(프로토타입)을 구현했습니다. 추후 React를 사용해 구체화할 예정입니다. 

## 3. 핵심 기술 연동 방안 연구
- 프로젝트의 깊이를 더하기 위해, SSAFY에서 제공된 기술 명세서를 학습하고 우리 프로젝트와의 접목 방안을 연구했습니다.

- AI 기술 활용 방안 모색: 공통으로 제공된 AI 명세서를 학습하고, '핀블' 게임의 이벤트 카드에 생성형 AI를 활용하여 동적이고 교육적인 콘텐츠를 제공하는 방안을 구체적으로 구상했습니다.

- 금융 콘텐츠 연동 방안 고민: 금융 명세서를 분석하며, 게임의 핵심인 금융 학습 요소를 단순히 텍스트로 보여주는 것을 넘어, API 기능과 어떻게 유기적으로 결합하여 사용자 경험을 높일 수 있을지 고민했습니다.

## 4. 다음 주 계획
- 이번 주에 직접 구현한 HTML/CSS 프로토타입을 바탕으로, 다음 주부터는 React 컴포넌트화 작업을 본격적으로 시작하여 프론트엔드 개발의 기반을 다질 예정입니다.
